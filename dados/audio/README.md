# Áudio de entrada

Largue aqui o áudio que vai virar legenda de reel (grave no celular mesmo, `.mp3`, `.m4a` ou `.wav`).

A skill `/reels` procura nesta pasta primeiro, transcreve no seu computador (sem chave de API, sem
mandar o arquivo pra lugar nenhum), mostra o texto pra você corrigir palavra ouvida errada e só
então renderiza o vídeo com a legenda igual ao que você falou.

O áudio em si não vai pro git.
