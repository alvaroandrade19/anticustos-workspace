# Biblioteca dos Mestres

Biblioteca de ensino de ofício e estrutura que acompanha o CopyOS. Ela aprofunda; quem decide é o motor
(`copy-de-conversao`) e o revisor (`revisor-chefe`). Os volumes têm cerca de 816 mil tokens no total, então a
regra de uso é uma só: **leia a seção, nunca o volume**. Localize pelo índice abaixo ou com `grep -n '^# \|^## '`
no arquivo, e leia só o trecho.

## Antes de usar qualquer volume

Leia `references/produto/3-biblioteca-dos-mestres/COMO-USAR-ESTA-BIBLIOTECA.md` uma vez por trabalho. O essencial:

- **Exemplos são ficção didática.** Estudos, instituições, estatísticas, taxas de conversão, depoimentos, nomes e
  preços dos exemplos existem para mostrar estrutura. Nenhum entra em copy, pesquisa ou proposta como fato. Isso
  vale em dobro aqui: o `PRODUCT.md` proíbe fabricar prova, e todo número de peça segue a regra das duas fontes
  (dado público com fonte, ou conta aberta com a base à mostra).
- **Regras confiantes são heurísticas** de uma escola de prática, não leis.
- **As skills e as regras da casa vencem a biblioteca** quando discordam. Em especial: zero travessão, nenhuma
  construção "não é X, é Y" nem "não é só X, é Y" (vários modelos de texto da biblioteca usam essa forma: copie a
  estrutura do argumento, nunca a frase), prova faltando vira `[placeholder]` nomeado, urgência e escassez só
  quando verdadeiras, nada de autoridade emprestada nem enquadramento de conspiração.
- **Copie o esqueleto, nunca a alegação.** Construa cada linha com fatos do negócio e palavras dos clientes.

**Numeração:** os volumes se chamam internamente DOC 0 a 13, e os arquivos vão de 01 a 14. "Doc N" dentro do texto
é o arquivo N+1 (Doc 5 = `06-estruturas-universais.md`). A Biblioteca dos Mestres também numera os níveis de
consciência ao contrário: "Estado 1" é o totalmente consciente e "Estado 5" o inconsciente. Nomeie o nível em
palavras para não errar o lead.

## Contexto deste workspace

Esta skill é consulta e nunca é fonte de fato sobre o negócio. Fatos vêm de `_contexto/`, `PRODUCT.md` e, para
cliente, de `clientes/<nome>/`. O mapa de qual mestre é dono de cada etapa de uma peça, com as seções exatas desta
biblioteca, está em `copy-de-conversao/references/os-mestres-por-etapa.md`.
